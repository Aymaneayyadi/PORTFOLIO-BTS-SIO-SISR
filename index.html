Qu'est-ce que la Veille Technologique ?

Définition et importance pour un administrateur SISR

La veille technologique est un processus continu de surveillance, d'analyse et de collecte d'informations sur les évolutions technologiques dans son domaine d'expertise.

Objectifs principaux :

  • Anticiper les nouvelles technologies et tendances
  • Maintenir et actualiser ses compétences techniques
  • Identifier les opportunités d'amélioration de l'infrastructure
  • Comprendre les évolutions des solutions existantes
  • Préparer les migrations et évolutions du parc informatique

Pour un administrateur SISR, la veille technologique est essentielle pour :

Sécurité des systèmes

Optimisation des performances

Automatisation des tâches

Évolution vers le cloud

Dans ce cadre, ma veille se concentre particulièrement sur la virtualisation VMware et l'administration des services Windows Server.

C'est quoi la Virtualisation ?

La virtualisation est une technologie qui permet de créer plusieurs environnements informatiques simulés (machines virtuelles) à partir d'un seul système physique.

Dans le cadre de mon projet AP3, j'ai déployé une infrastructure complète sous VMware Workstation Professional, incluant plusieurs machines virtuelles Windows Server 2022 pour simuler un environnement d'entreprise réel.

Pourquoi virtualiser ?
  • Optimisation des ressources matérielles
  • Isolation des environnements
  • Facilité de déploiement et de migration
  • Récupération rapide après incident (snapshots)
  • Réduction des coûts matériels

Les Différents Types de Virtualisation

La virtualisation peut être catégorisée selon plusieurs approches, chacune répondant à des besoins spécifiques

Virtualisation de Serveurs

Création de plusieurs machines virtuelles sur un seul serveur physique

Ex: VMware vSphere, Microsoft Hyper-V

Virtualisation de Postes

Exécution d'environnements de bureau virtualisés sur un PC local

Ex: VMware Workstation, VirtualBox

Virtualisation Réseau

Création de réseaux virtuels indépendants de la topologie physique

Ex: VMware NSX, VLANs, SD-WAN

Virtualisation Stockage

Agrégation de ressources de stockage physiques en pools virtuels

Ex: VMware vSAN, RAID virtuel

Hyperviseurs : Type 1 vs Type 2

Hyperviseur Type 1 (Bare Metal)

S'installe directement sur le matériel physique. Aucun système d'exploitation hôte requis.

Caractéristiques :
  • Performance maximale (accès direct au matériel)
  • Stabilité et sécurité accrues
  • Utilisé en production et data centers
Exemples : VMware ESXi, Microsoft Hyper-V, Xen, KVM

Hyperviseur Type 2 (Hosted)

S'installe comme une application sur un système d'exploitation hôte.

Caractéristiques :
  • Facile à installer et configurer
  • Idéal pour développement, tests, labs
  • Performance moindre (via OS hôte)
Exemples : VMware Workstation, Oracle VirtualBox, Parallels
Dans le cadre de mon projet :

J'ai utilisé VMware Workstation (Type 2) pour créer un environnement de test complet sur mon poste local. Ce choix permet une grande flexibilité pour les tests, snapshots et la portabilité de l'infrastructure complète.

Scripts et commandes utilisés

PS
Active Directory & DNS 
# Installer le rôle AD DS
Install-WindowsFeature AD-Domain-Services -IncludeManagementTools

# Promouvoir en contrôleur de domaine
Install-ADDSForest -DomainName "entreprise.local" `
  -DomainNetbiosName "ENTREPRISE" -InstallDNS

# Créer un nouvel utilisateur
New-ADUser -Name "Dupont Jean" -SamAccountName "jdupont" `
  -UserPrincipalName "jdupont@entreprise.local" -Enabled $true

# Créer un groupe
New-ADGroup -Name "Admins Département" -GroupScope Global

# Vérifier les services DNS
Get-DnsServerZone | Format-Table ZoneName, ZoneType
PS
DHCP & GPO 
# Installer le rôle DHCP
Install-WindowsFeature DHCP -IncludeManagementTools

# Créer une étendue DHCP
Add-DhcpServerV4Scope -Name "LAN Principal" `
  -StartRange 192.168.1.100 -EndRange 192.168.1.200 `
  -SubnetMask 255.255.255.0

# Réserver une adresse IP
Add-DhcpServerv4Reservation -ScopeId 192.168.1.0 `
  -IPAddress 192.168.1.150 -ClientId "00-15-5D-02-4B-01"

# Créer une GPO
New-GPO -Name "Politique Sécurité Bureau"

# Lier une GPO à une OU
New-GPLink -Name "Politique Sécurité Bureau" `
  -Target "OU=Utilisateurs,DC=entreprise,DC=local"
PS
Monitoring & Administration 
# Vérifier l'état des services
Get-Service | Where-Object {$_.Status -ne "Running"}

# Analyser l'espace disque
Get-WmiObject Win32_LogicalDisk | Select-Object DeviceID, `
  @{Name="Size(GB)";Expression={[math]::Round($_.Size/1GB,2)}}, `
  @{Name="Free(GB)";Expression={[math]::Round($_.FreeSpace/1GB,2)}}

# Vérifier les événements système
Get-EventLog -LogName System -Newest 20 | `
  Select-Object TimeGenerated, EntryType, Source, Message

# Tester la connectivité réseau
Test-NetConnection -ComputerName "DC01" -Port 53
Test-NetConnection -ComputerName "DC01" -Port 389
